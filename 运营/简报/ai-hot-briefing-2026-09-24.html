今日主线：一小时之内的两连发——价格战打到了成本结构的最深处

9 月 22 日深夜到 23 日凌晨，Anthropic 发布 Claude Opus 5.5（$4/$20，典型任务成本 -40%），约一小时后 OpenAI 跟进 GPT-6 Sol 与 Luna（较上代直接减半，Luna $0.10/$0.50 成 OpenAI 史上最便宜的实用模型）——Simon Willison 称之为「新价格战」，而旗舰 Astra 与 Fable 5.1 默契地按兵不动，挨打的是第二梯队。真正值得注意的是价格表里降得最狠的那一列：Opus 5.5 缓存读取直降 60%，GPT-6 缓存改版让新鲜处理 token 减半——Agent 工作流里九成输入走缓存价，两家都在给「跑在 Agent 里的模型」定向降价。同一天，五角大楼调查认定过度依赖 Maven AI 是误击伊朗学校的原因之一，DeepSeek 公开每秒造 5000 个沙盒的 Agent 训练基础设施。三条线合起来读：模型的单位智能在变便宜，模型的单位风险在变贵，而训练与约束模型的基建，正在成为新的主战场。

Anthropic「实战笔记」系列新篇，把数年缩到数周的 AI 代码现代化项目拆成六步：定义目标（Uplift 升级 / Transform 跨栈重写 / Reimagine 重塑三型）、定义认证标准（每项变更须满足的机器可自动检查的条件集，与审查者共同编写）、设定晋升政策（按影响范围与置信度分级审查，关键路径保留人工）、落实先决条件（环境、CI/CD、团队协议、安全合规）、构建智能体工作流（Claude Code 多子智能体并行，出问题改工作流而非逐个修变更）、小分区端到端跑通再铺开。核心洞察一句：智能体加速了变更的编写之后，瓶颈从「产生变更」转移到「动员整个组织围绕变更工作」；验证而非生成才是 token 成本大头。这是目前关于「AI 大规模改造遗留系统」最可抄的组织方法论。
